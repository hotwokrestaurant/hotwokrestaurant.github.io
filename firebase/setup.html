4. Tests while signed in as the owner

5. Restore from a backup file

Choose a file saved with "Download backup" on the admin page. Sign in first (step 2) and tick "Replace the menu…" in step 3.

6. One-time upgrade: menu sections

Gives every section a permanent id, so the owner can add, rename, reorder and hide sections. Only needed once, for a menu created before this change. Sign in first (step 2).
